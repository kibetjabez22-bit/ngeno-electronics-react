# 🛒 NGENOS Electronics

NGENOS Electronics is a modern e-commerce web application built with **React**, **Vite**, and **Firebase**. It provides a fast, secure, and user-friendly shopping experience for electronics, including smartphones, laptops, smartwatches, accessories, and other technology products.

---

## ✨ Features

- Responsive design
- Modern homepage with animated hero section
- Product catalogue
- Product search and category filtering
- Product details page
- Shopping cart
- Wishlist
- User authentication (Firebase Authentication)
- Firebase Firestore database
- Firebase Storage for product images
- Checkout page
- Product reviews and ratings
- Dark/Light mode
- Mobile-friendly navigation

---

## 🛠️ Technologies Used

- React
- Vite
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Hosting
- React Router
- CSS3
- JavaScript (ES6+)

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/ngenos-electronics.git
```

Navigate to the project:

```bash
cd ngenos-electronics
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
